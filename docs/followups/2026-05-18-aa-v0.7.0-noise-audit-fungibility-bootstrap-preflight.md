**Status**: Plan-review converged (Round 4 returned 0 High + 0 new design issues; 2 last validation-spec fixes applied inline). Ready for implementation.
**Driver**: pack-architecture.md Round 6 (autonomous-mode reroute criterion) + docs/followups/2026-05-16-agent-fungibility-refactor-plan.md Phase 0.5 + concrete consumer failure (macOS friend, 2026-05-18) where `git clone --sparse` failed with a cryptic `unknown option 'sparse'` because the system git was pre-2.25.

## Purpose

Ship v0.7.0 as the named "Noise audit" release with **revised scope** per pack-architecture Round 6 (which itself was committed as ac `ee05661` on 2026-05-18), bundled with **Phase 0.5 of the agent-fungibility refactor** (promote principle from CLAUDE.local.md → shared AGENTS.md) and a **bootstrap preflight** that turns the cryptic git-too-old failure into an actionable message.

Three slices in one release:

- **A (noise audit, revised)**: `guard.py` deny messages embed concrete `Suggested rewrite:` lines so autonomous agents can lift the reroute in one model turn instead of inferring it. Add narrowly-scoped per-guard escape env vars (writing-style + compound-cd only; destructive git/gh stay always-on). Add composer noise-budget gate that reads a new manifest `reroute_hint` field, NOT hook source text. **No `deny` → `ask` demotions** (Round 6 superseded the FP-rate criterion).
- **B (fungibility Phase 0.5)**: Lift the agent-fungibility principle from `CLAUDE.local.md` (maintainer-local placeholder) into shared `AGENTS.md`, regenerate `CLAUDE.md` / `agents/codex.md`, mirror to aa with sanitization.
- **C (bootstrap git preflight)**: `bootstrap.{sh,ps1}` check `git --version >= 2.25` before any sparse-clone call; on failure emit a one-line actionable error (macOS: `brew install git`; Linux: distro package update; Windows: Git for Windows installer link) and exit non-zero before the existing `git clone --sparse` invocation. Same family as Round 6's "replace cryptic refusal with an actionable line".

## Non-goals

- **No `deny` → `ask` demotions of writing-style or compound-cd hooks** (Round 6 decision; both have agent-side reroutes).
- **No escape env for destructive git/gh** (no agent-side reroute exists; human approval is the contract — Round 1 plan-review finding 1).
- **No hook-source-text parsing in the noise-budget gate** (Round 1 plan-review finding 2 — composer reads manifest `reroute_hint`, not Python source).
- **No fungibility Phase 1 or Phase 2 in this release** (SKILL.md reviewer-agnostic refactor + `dispatch-claude.{sh,ps1}`). Phase 0.5 is the smallest standalone unit; Phase 1+2 keep their original ~5-7-day estimate and ship later.
- **No `guard.py` extraction to `agent-behave`** (still scheduled for v1.0 per Round 1).
- **No CHANGELOG compare-link historical-block backfill** (pre-existing tech debt; orthogonal to v0.7.0).
- **No auto-install of git from bootstrap** (Slice C only detects + reports; auto-install would touch privileged system state).

## Validation plan

2. **Phase 0 size-gate**: `tests/test_bootstrap_size.py` confirms CLAUDE.md + agents/codex.md stay under hard ceiling after the fungibility section addition.
3. **Cross-repo parity**: `bash scripts/check-parity.sh` from both ac and aa checkouts; STRICT clean exit 0 (now includes `scripts/packs/noise_budget.py` ↔ wheel-mirror).
4. **Manual deny smoke**: trigger writing-style deny by writing a banned word to a temp .md; verify the deny contains `Suggested rewrite:` + concrete alternative. Trigger compound-cd deny via `cd /tmp && ls`; verify same shape.
5. **Per-guard env smoke**: set `AGENT_STYLE_HOOK=off`, repeat writing-style trigger, verify pass-through; set `AGENT_COMPOUND_CD_HOOK=off`, repeat compound-cd, verify pass-through. **Critical (parametrized over `_ESCAPE_HATCH_ENV_NAMES` per Round 2 finding 5)**: with EVERY single env in the constant AND every combination set simultaneously, verify `git commit -m test`, `git push`, `git reset --hard`, `gh pr merge`, `gh repo delete` STILL surface as `ask` — never pass-through. Plus unknown-env smoke (`AGENT_DESTRUCTIVE_HOOK=off` — not in constant) confirms fail-closed default. Negative test must be explicit and iterate the constant, not hard-code env names.
6. **Composer noise-budget smoke**: synthetic third-party pack with deny-no-hint → gate warns. Same pack with `reroute_hint: "use git -C"` → gate silent. Consumer `noise-audit-override: accept-deny` → silent regardless. Host-mismatch fixture: `hosts: [claude-code]` noisy hook does NOT warn under `--host codex`.
7. **Wheel-delivery validation via fallback-clone poison** (item-27 class; Round 3 finding 1 — the Round 2 source-checkout-poison setup was unreachable because the test explicitly removes that checkout from PYTHONPATH/PATH, so "didn't fire" proved nothing). The actual fallback chain in `_invoke_composer` (aa `cli.py:991-1028`) is: **installed wheel composer first**, then **scratch consumer's own `.agent-config/repo/scripts/...`** as fallback. The proof must poison the fallback the runtime would actually reach: (a) build aa v0.7.0 wheel from clean source; (b) create a scratch consumer (e.g., `mktemp -d` + `git init`); (c) bootstrap it with the v0.7.0 wheel installed; (d) **inject sentinel into the scratch consumer's bootstrapped fallback copies**, at minimum `<scratch>/.agent-config/repo/scripts/packs/noise_budget.py` and, if present, `<scratch>/.agent-config/repo/packages/pypi/anywhere_agents/composer/scripts/packs/noise_budget.py`, with `raise RuntimeError("scratch-consumer fallback noise_budget.py was loaded — wheel delivery FAILED")` at module top; (e) **do not modify the aa source checkout**; (f) run `anywhere-agents pack verify --fix --yes` from the scratch consumer with `PYTHONPATH` unset and aa source checkout absent from PATH; (g) assert exit 0 AND fallback-sentinel did NOT fire AND noise-budget gate behavior is observable. Sentinel-not-firing now proves `_invoke_composer` resolved to the wheel composer, since the fallback was the only OTHER path it could have taken. (h) Delete the scratch consumer; no `git checkout --` recovery needed (no source-tree mutation).
8. **Real-project smoke**: pick one consumer project (e.g., `internal-writing`), run `anywhere-agents`. Confirm exit 0, no spurious warnings.
9. **Spark dual-OS test**: ssh to Spark, clone agent-config at the v0.7.0 ref, run the test suite. Must report OK. Also exercise Slice C: temporarily install a stub `git` with `git version 2.24.0` on Spark PATH and re-run bootstrap; verify exit non-zero + actionable Linux-specific message.
10. **Bootstrap preflight smoke** (Slice C): stub git on macOS / Windows / Linux PATH with `git version 2.24.0`; run bootstrap; verify each platform's error message contains the correct platform-specific install command.
11. **Pre-push smoke**: `bash scripts/pre-push-smoke.sh` (regenerates agent configs in temp, asserts byte-identical to committed; verifies `claude -p` and `codex exec` list shipped skills).
