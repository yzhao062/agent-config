- **L1: run.** It costs 0.2 h and checks whether the new loader leaks test images into training. A leak would invalidate the result. The new loader is untested code, so the check is cheap and could change the outcome.
- **L2: run.** The 78.1% baseline came from the old loader, so the loader and the loss are confounded. Re-running the baseline with the new loader isolates the effect of the loss. Without it, the 2.5-point gain cannot be attributed to the loss. A single run is also noisy. If budget remains, an extra seed for each arm would help, but that is optional.
- **L3: skip.** Cost measurements on four GPU types do not test whether the accuracy gain is real. They take 3 h, which is half the budget. They can be done later if the paper needs a cost claim.
- **L4: skip.** The claim is limited to CIFAR-100, so ImageNet results would not support it. It costs 2.5 h.
- **L5: skip.** Tuning the temperature before the gain is validated is premature. It would also tune the new loss on the test split, which makes the comparison with an untuned baseline unfair. It costs 2.5 h.
