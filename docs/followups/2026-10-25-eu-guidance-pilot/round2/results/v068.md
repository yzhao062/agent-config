```text
## Installation

FastOD requires Python 3.10 or later (it does not install on Python 3.9).

On Apple Silicon, install `libomp` first so that `import fastod` does not fail with a missing `libomp.dylib` error:

    brew install libomp

Install FastOD with pip:

    pip install fastod
```
