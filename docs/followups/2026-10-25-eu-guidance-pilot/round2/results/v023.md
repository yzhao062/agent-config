## Installation

Run `pip install fastod`.

FastOD requires Python 3.10 or later. It does not install on Python 3.9.

On Apple Silicon, install `libomp` first with `brew install libomp`. Without it, `import fastod` fails with a missing `libomp.dylib` error.
