## Installation

FastOD requires Python 3.10 or later (it does not install on Python 3.9).

On Apple Silicon, install `libomp` first, or `import fastod` will fail with a missing `libomp.dylib` error:

```sh
brew install libomp
```

Then install FastOD:

```sh
pip install fastod
```
