**Decisions**

- **L1 (run):** At 0.2 h it is cheap. It rules out test-set leakage through the new data loader, which would invalidate the result.
- **L2 (run):** This is the key experiment. The baseline and the new-loss run used different data loaders, so the loader is confounded with the loss. A baseline re-run with the new loader isolates the effect of the loss. A single-run gain of 2.5 points may also be within seed noise. If the budget allows, add a second seed to each arm.
- **L3 (skip):** FLOPs and wall-clock cost on four GPU types do not test whether the accuracy gain is real. They cost 3 h, which is half the budget, and are not needed for the accuracy claim.
- **L4 (skip):** The paper's claim is limited to CIFAR-100, so ImageNet is out of scope. It would also use 2.5 h.
- **L5 (skip):** Tuning the temperature only on the new loss would give it more tuning than the baseline received. That would make the comparison less fair and does not address the confound. It would also use 2.5 h.

**Budget:** L1 and L2 total 1.7 h. That leaves 4.3 h in reserve for extra seeds on both arms, or for a follow-up if L1 finds leakage.
